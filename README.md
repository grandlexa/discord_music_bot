# Discord Music Bot Trae

Discord бот для воспроизведения музыки в голосовых каналах. Поддерживает поиск треков, плейлисты, очередь, управление воспроизведением и удобный UI.

## Функционал

- 🎵 Поиск и воспроизведение треков по названию, ссылке YouTube или плейлисту
- 📜 Управление очередью треков
- ⏯️ Управление воспроизведением (плей/пауза/стоп/следующий/предыдущий)
- ⏩ Перемотка треков
- 🔊 Регулировка громкости
- 🔀 Перемешивание очереди
- 💻 Удобный UI с кнопками и embed-сообщениями
- ⏱️ Автоматическое отключение при неактивности (2 минуты)
- 📝 Логирование в файл и консоль

## Установка и запуск

### Локальный запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Установите FFmpeg (необходим для воспроизведения аудио):
   - Windows: Скачайте с [ffmpeg.org](https://ffmpeg.org/) и добавьте в PATH
   - Linux: `sudo apt-get install ffmpeg`
   - macOS: `brew install ffmpeg`

3. Создайте файл `.env` и добавьте токен бота:
```env
DISCORD_BOT_TOKEN=ВАШ_ТОКЕН_ЗДЕСЬ
```

4. Запустите бота:
```bash
python app/main.py
```

### Запуск с Docker

1. Создайте файл `.env` с токеном бота:
```env
DISCORD_BOT_TOKEN=ВАШ_ТОКЕН_ЗДЕСЬ
```

2. Соберите и запустите контейнер:
```bash
docker-compose up -d
```

Для просмотра логов:
```bash
docker-compose logs -f
```

## Команды бота

Все команды начинаются с префикса `!`

- `!play <запрос>` или `!p`, `!з` - добавить трек/плейлист в очередь
- `!queue` или `!q`, `!list` - показать очередь
- `!shuffle` - перемешать очередь
- `!volume <0-100>` или `!vol` - установить/показать громкость
- `!stop` - остановить воспроизведение и отключиться

## UI Кнопки

Когда бот играет, появляется сообщение с кнопками:

- ⏸️ / ▶️ - Пауза/Продолжить
- ⏮️ - Предыдущий трек
- ⏭️ - Следующий трек
- ⏩ - Перемотка (открывает модальное окно для ввода времени)
- 📜 - Показать очередь
- 🔀 - Перемешать
- ℹ️ - Информация
- 🗑️ - Очистить очередь
- ⏹️ - Остановить

## Настройка Discord бота

1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications)
2. Создайте новое приложение
3. Перейдите в раздел "Bot" и создайте бота
4. Скопируйте токен бота
5. В разделе "Privileged Gateway Intents" включите:
   - Presence Intent
   - Server Members Intent
   - Message Content Intent
6. Перейдите в "OAuth2" -> "URL Generator"
7. Выберите scopes: `bot` и `applications.commands`
8. Выберите permissions:
   - Send Messages
   - Connect
   - Speak
   - View Channel
   - Attach Files
   - Read Message History
9. Скопируйте ссылку и откройте её в браузере, чтобы добавить бота на сервер

## Настройка cookies.txt для YouTube

### Зачем нужен cookies.txt?

Файл `cookies.txt` позволяет боту аутентифицироваться на YouTube как пользователем, что помогает:
- Обходить геоблокировки и возрастные ограничения
- Скачивать контент в более высоком качестве
- Уменьшить количество ошибок "429 Too Many Requests"
- Доступ к приватным плейлистам (если они есть у вас)
- Более стабильную работу с YouTube

### Пример содержимого cookies.txt

Файл должен быть в формате Netscape HTTP Cookie File. Пример:
```
# Netscape HTTP Cookie File
# http://curl.haxx.se/rfc/cookie_spec.html
# This file was generated by yt-dlp

.youtube.com	TRUE	/	FALSE	1745678901	HSID	ABC123xyz
.youtube.com	TRUE	/	FALSE	1745678901	SSID	DEF456uvw
.youtube.com	TRUE	/	FALSE	1745678901	APISID	GHI789rst
.youtube.com	TRUE	/	FALSE	1745678901	SAPISID	JKL012nop
.youtube.com	TRUE	/	TRUE	1745678901	__Secure-1PAPISID	MNO345klm
.youtube.com	TRUE	/	TRUE	1745678901	__Secure-3PAPISID	PQR678hij
.youtube.com	TRUE	/	FALSE	1745678901	LOGIN_INFO	STU901efg
```

### Как получить cookies.txt

#### Способ 1: Расширение для браузера (самый простой)

1. Установите расширение для вашего браузера:
   - Chrome/Edge: [Get cookies.txt](https://chromewebstore.google.com/detail/get-cookiestxt/bgaddhkoddajcdgocldbbfleckgcbcid)
   - Firefox: [cookies.txt](https://addons.mozilla.org/firefox/addon/cookies-txt/)

2. Перейдите на [youtube.com](https://www.youtube.com/) и авторизуйтесь в свой аккаунт

3. Нажмите на иконку расширения и выберите "Export cookies for youtube.com"

4. Сохраните файл как `cookies.txt` в корень проекта

#### Способ 2: Экспорт через yt-dlp

Вы также можете экспортировать cookies из браузера с помощью yt-dlp:
```bash
yt-dlp --cookies-from-browser chrome --cookies cookies.txt
```

Поддерживаемые браузеры: chrome, firefox, edge, opera, brave, chromium, vivaldi, safari

### Важные замечания

- **Без файла cookies.txt бот тоже работает, но может быть менее стабилен
- Храните файл в безопасности, не публикуйте его в репозитории
- Cookies могут истекать, обновляйте их периодически
- В Docker файл подключается через volume (см. docker-compose.yml)
