# Requirements Document

## Overview
Этот проект представляет собой многофункционального музыкального бота для Discord, способного воспроизводить аудио из YouTube (включая плейлисты) с поддержкой очередей, плавного изменения громкости (fade-in/fade-out) и интерактивного UI.

## Business Requirements
- Предоставить пользователям Discord удобный способ совместного прослушивания музыки.
- Обеспечить высокую стабильность воспроизведения и качество звука.
- Снизить порог вхождения для управления ботом через интуитивный интерфейс кнопок.

## Functional Requirements

### Core Features
1. **Воспроизведение аудио**
   - Поддержка ссылок YouTube и поиск по названию.
   - Обработка одиночных видео и целых плейлистов.
   - Плавное нарастание громкости в начале и затухание в конце трека.

2. **Управление очередью**
   - Просмотр текущей очереди.
   - Перемешивание (shuffle) будущих треков.
   - Переключение на следующий/предыдущий трек.
   - Очистка очереди при остановке.

3. **Интерактивный плеер**
   - Сообщение с кнопками управления (Play/Pause, Skip, Stop, Seek, Shuffle).
   - Динамическое обновление информации о текущем треке и громкости.
   - Модальные окна для точной перемотки трека.

4. **Автоматизация**
   - Автоматическое отключение от голосового канала при бездействии (120 секунд).
   - Обработка ошибок подключения и недоступности видео.

### User Stories
- Как пользователь, я хочу вставить ссылку на плейлист, чтобы бот автоматически добавил все треки в очередь.
- Как пользователь, я хочу нажать кнопку паузы в интерфейсе, чтобы быстро остановить музыку без ввода команд.
- Как пользователь, я хочу перемотать трек на определенное время через удобное окно ввода.

## Non-Functional Requirements

### Performance
- Минимальная задержка при поиске и начале воспроизведения (использование `run_in_executor` для блокирующих вызовов).
- Эффективное использование ресурсов FFmpeg для стриминга.

### Security
- Безопасное хранение токена бота через переменные окружения (.env).
- Использование cookies.txt для обхода ограничений YouTube.

### Usability
- Весь интерфейс и сообщения бота должны быть на русском языке.
- Поддержка slash-команд или префиксных команд (текущая реализация: префикс `!`).

## Technical Constraints
- Язык программирования: Python 3.12.
- Библиотеки: `discord.py`, `yt-dlp`, `PyNaCl`.
- Внешние зависимости: FFmpeg.
- Контейнеризация: Docker, Docker Compose.

## Acceptance Criteria
1. Бот успешно подключается к голосовому каналу пользователя.
2. Команда `!play` корректно обрабатывает как ссылки, так и поисковые запросы.
3. Кнопки в `MusicPlayerView` выполняют соответствующие действия (пауза, пропуск и т.д.).
4. Бот автоматически отключается, если музыка не играет более 2 минут.

## Out of Scope
- Поддержка Spotify/SoundCloud (на текущем этапе).
- Система уровней или экономика.
- Веб-панель управления.

## Dependencies
- YouTube API (через yt-dlp).
- Discord API.
- FFmpeg для обработки аудиопотока.

## Risks and Assumptions
### Risks
- Изменение алгоритмов YouTube может привести к поломке `yt-dlp` (требуется регулярное обновление).
- Блокировка IP-адреса хостинга со стороны YouTube (решается через прокси или cookies).

### Assumptions
- У пользователя есть стабильное интернет-соединение.
- Бот имеет необходимые права на сервере (Connect, Speak, Use Voice Activity).
