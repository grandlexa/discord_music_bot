# Task List

## Overview
План реализации музыкального бота Discord с нуля, разделенный на логические фазы для обеспечения стабильности и масштабируемости.

## Phase 1: Foundation
### Setup & Configuration
- [ ] Инициализация проекта и виртуального окружения Python.
- [ ] Настройка логирования в файл и консоль.
- [ ] Создание системы конфигурации через переменные окружения (.env).
- [ ] Подготовка Dockerfile и docker-compose.yml для FFmpeg и зависимостей.

### Core Infrastructure
- [ ] Реализация базового класса бота с обработкой событий `on_ready`.
- [ ] Создание структуры сервисов (YoutubeService, QueueService).
- [ ] Настройка базовых Intents (VoiceStates, MessageContent).

## Phase 2: Core Features
### Музыкальный движок
- [ ] Интеграция `yt-dlp` для поиска и извлечения метаданных.
- [ ] Реализация асинхронного извлечения прямых ссылок на потоки.
- [ ] Настройка FFmpeg с параметрами переподключения для стабильного стриминга.

### Управление очередью
- [ ] Реализация логики добавления треков и плейлистов.
- [ ] Создание функции `play_next` с рекурсивным вызовом после завершения трека.
- [ ] Реализация механизмов перемешивания (shuffle) и навигации (next/prev).

## Phase 3: Integration & Testing
### Интерактивный UI
- [ ] Создание `MusicPlayerView` с кнопками управления.
- [ ] Реализация `SeekModal` для перемотки трека.
- [ ] Добавление динамических Embed-сообщений с прогресс-баром и обложками.

### Тестирование и отладка
- [ ] Тестирование обработки некорректных ссылок и недоступных видео.
- [ ] Проверка работы таймера автоматического отключения.
- [ ] Отладка эффектов плавного изменения громкости (fade-in/out).

## Phase 4: Polish & Documentation
### UI/UX Refinements
- [ ] Локализация всех системных сообщений на русский язык.
- [ ] Улучшение визуального отображения очереди (пагинация для длинных списков).
- [ ] Оптимизация удаления старых сообщений плеера для чистоты чата.

### Documentation
- [ ] Создание README.md с инструкцией по запуску и списком команд.
- [ ] Документирование API сервисов для будущих расширений.
- [ ] Подготовка файла с примерами cookies.txt.

## Task Dependencies
- Воспроизведение (Core) зависит от корректной настройки FFmpeg (Foundation).
- UI кнопки зависят от наличия методов управления в QueueService.
- Docker-сборка зависит от полноты requirements.txt.

## Critical Path
1. Настройка окружения и Docker.
2. Базовое подключение к голосовому каналу.
3. Поиск и стриминг через yt-dlp.
4. Логика автоматического перехода к следующему треку.

## Risk Mitigation Tasks
- [ ] Реализация автоматического обновления yt-dlp при запуске контейнера.
- [ ] Добавление обработки ошибки 403 (Forbidden) с ротацией User-Agent.
